---

![Tweet by @staysaasy about a 2018 code review](/images/tweet-staysaasy.png)

I used to care a lot about my code. Naming conventions, folder structure, where things lived — I'd sit with a bad name for too long because it bothered me. Spend an hour refactoring something that already worked because the shape felt wrong. Coworkers knew to expect long PRs with opinions in the comments.

That's what this tweet is about. 400 line PRs you actually read. A coworker who pushed back because they disagreed, not because they were being difficult. Caring enough about the code that it showed up in your sleep.

I don't know exactly when that stopped. The models got good, the timelines got shorter, and at some point I stopped agonizing over names because something else was writing them. It's faster. The output is fine most of the time. But I've noticed I can't always tell what I built versus what got generated, even in my own projects.

Still using Claude. Still going to. The craft part though, I'm not sure where it went.
